job-search-automation

A pipeline that job-hunts while you don't.

Already running daily for a few friends' searches.

What it does

  • Pulls new postings daily — target companies' own career pages, plus the open market
  • Scores every posting against your real experience, with the exact evidence behind each score
  • Surfaces the fine print — comp, remote policy, sponsorship, parental leave — quoted, never guessed
  • One dashboard: sourcing → triage → leads → interviews

How it helps your search

  • No more manually checking a dozen career pages a day
  • No more re-reading a JD for ten minutes to guess if you qualify
  • Never miss a sponsorship clause or RTO policy buried in paragraph six
  • Never sends an application for you — you stay in control, always

Setup

~30–45 min once. Then it just runs.

  1. Spin up your own free Supabase project — your data, never shared
  2. Run the SQL migrations in order — paste, click, done, no installer
  3. Drop in your API keys and your own experience history
  4. Set your target companies and roles, once
cd worker
pip install -e .
python -m worker run --scheduled-for "$(date -u +%Y-%m-%dT%H:%M:%SZ)"

Or let it run daily on its own, unattended, via GitHub Actions.

Fully independent instance: your own Supabase project, your own keys, your own data. Nothing shared, nothing sent anywhere else — and no code path in it can ever submit an application for you.
